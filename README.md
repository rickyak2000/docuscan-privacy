 # Kebijakan Privasi DocuScan
  
    Terakhir Diperbarui: 14 Oktober 2026
  
    DocuScan menghormati dan melindungi privasi setiap pengguna aplikasi DocuScan. Kebijakan ini menjelaskan bagaimana data Anda dikelola:
  
    ### 1. Pemrosesan Dokumen Lokal (On-Device)
    - DocuScan tidak mengunggah berkas pindaian, gambar, foto identitas (KTP/NPWP/BPJS), atau tanda tangan digital Anda ke server eksternal kami.
    - Seluruh pemrosesan crop otomatis, kompresi, dan penggabungan PDF dijalankan 100% secara lokal di dalam memori perangkat ponsel Anda.
  
    ### 2. Izin Aplikasi
    - **Kamera**: Digunakan semata-mata untuk memindai dokumen fisik menjadi file PDF.
    - **Penyimpanan / Media**: Digunakan untuk membaca gambar yang ingin diimpor dan menyimpan file PDF yang telah selesai dibuat.
  
    ### 3. Layanan Iklan Pihak Ketiga (Google AdMob)
    Aplikasi versi gratis didukung oleh iklan dari Google AdMob. Google Mobile Ads SDK dapat mengumpulkan pengenal perangkat non-pribadi (seperti Device ID atau IP address) untuk penayangan   
  iklan yang sesuai dan pencegahan kecurangan traffic (AdMob Policy). Anda dapat membaca kebijakan periklanan Google di: https://policies.google.com/technologies/ads
  
    ### 4. Keamanan Dokumen
    Semua dokumen tersimpan di direktori privat aplikasi di ponsel Anda. Pengguna memiliki kendali penuh untuk menghapus, membagikan, atau mengunci dokumen dengan PIN/Biometrik.
  
    ### 5. Kontak Pengembang
    Jika Anda memiliki pertanyaan mengenai kebijakan privasi ini, silakan hubungi pengembang melalui email yang terdaftar di Google Play Console.
